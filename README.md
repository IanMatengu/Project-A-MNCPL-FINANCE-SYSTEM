## 4. Project Description

The Municipal Financial Management System (MFMS) is a simple C program with a menu interface used to manage financial and administrative tasks. It helps users track staff records, budgets, suppliers, and assets, and it can also create basic reports. This project brings together the programming basics taught in PAP521S, including variables, loops, decisions, arrays, strings, functions, and input checks.

## 5. System Features

The system is designed to include the following features:

### 5.1 Employee Management
- Add and display employee records.
- Search for employees.
- Calculate employee salary information.

### 5.2 Budget Management
- Enter departmental budgets and expenditure.
- Calculate remaining budgets.
- Determine whether expenditure is within budget.
- Identify departments that have exceeded their budgets.

### 5.3 Supplier Management
- Add and display supplier records.
- Search for suppliers.
- Maintain supplier contact information.

### 5.4 Asset Management
- Maintain a municipal asset register.
- Display and search asset information.

### 5.5 Reports
- Generate employee reports.
- Display budget summaries.
- Generate supplier and asset reports.

### 5.6 Main Menu
- Navigate between system modules.
- Exit the application.

## 6. Compilation Instructions

### Prerequisites

Ensure that the following tools are installed:

- GCC compiler
- Visual Studio Code or another C-compatible editor

### Compile the program

Open a terminal in the project directory and run:

- Bash
```bash
gcc -std=c99 -Wall -Wextra *.c -o mfms
```
- Powershell
```Powershell
gcc -std=c99 -Wall -Wextra *.c -o mfms.exe
```
## 7. How to Run the System

### Linux

```bash
./mfms
```

### Windows

```powershell
.\mfms.exe
```

- Generates accurate reports.
